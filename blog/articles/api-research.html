APIの通信内容

調査対象のサービスの利用規約やアクセス制限を確認し、許可された範囲で調査・利用してください。

1. 通信を確認する

自分が利用できるWebページを開き、ブラウザーの開発者ツールから Network（ネットワーク）を確認します。ページの更新時に発生する通信を見て、データ取得に関係するリクエストを探します。

  • リクエストのメソッド（GET / POST）
  • 送信先のURLと必要なパラメーター
  • リクエスト本文やContent-Type
  • レスポンスのステータスと本文

2. JSONの構造を読む

レスポンスがJSONの場合、最上位が配列なのかオブジェクトなのかを確認します。車両データの配列がどのキーに入っているか、位置情報がどの階層にあるかを順番に調べます。

{
  "vehicles": [
    {
      "id": "example",
      "latitude": 35.000,
      "longitude": 138.000
    }
  ]
}

上記は構造を説明するための架空データであり、特定のAPIの実レスポンスではありません。

3. ブラウザーから取得できない場合

ブラウザーのCORS制限や、API側が要求するHTTPメソッド・ヘッダーなどが原因で、JavaScriptから直接取得できない場合があります。その場合は、利用条件を確認したうえでサーバー側の処理を使う設計を検討します。

4. 調査メモに残す項目

  • 確認した日時と対象ページ
  • HTTPメソッドと必要なパラメーター
  • レスポンスの主要なキー
  • 更新頻度やエラー時の挙動
  • 利用規約・公開範囲に関する注意点
