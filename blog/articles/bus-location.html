バスロケ記録

バスの位置情報を取得し、地図上に表示する構成

。

1.

バスロケーションサイトでは、車両の緯度・経度を取得し、地図上にバスのマーカーとして表示。

2. 基本的な構成

  • データ取得：APIやサーバー側のPHPで車両データを取得する。
  • 地図表示：Leafletなどを使い、緯度・経度にマーカーを置く。
  • 車両情報：車両IDと表示用の車番などを対応付ける。
  • 定期更新：一定間隔でデータを再取得し、マーカーを更新する。
API / PHP
   ↓ 車両データ(JSON)
JavaScript
   ↓ 緯度・経度を読み取る
Leaflet map
   ↓
車両マーカーを表示

3. 開発中に確認すること

最初は、APIのレスポンスが想定したJSON形式か、緯度・経度が数値で入っているか、ブラウザーのコンソールにエラーが出ていないかを確認します。データ取得と地図描画を分けて検証すると、問題の切り分けがしやすくなります。

4. 次に改善したいこと

車両ごとの表示名、路線・行先、更新時刻、停留所表示、位置履歴などを段階的に追加していくと、実用的なサイトに近づきます。
